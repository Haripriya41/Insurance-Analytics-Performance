 Insurance-Analytics-Performance
Analyzed 1K+ insurance records to evaluate business performance, invoice trends, and Account Executive productivity. Built interactive KPI dashboards using Power BI and Tableau to monitor performance and support data-driven decision-making.
 Insurance Analytics Dashboard

 📊 Project Overview

An insurance analytics project focused on analyzing sales performance, invoice trends, renewals, cross-sell opportunities, and Account Executive productivity.

 🎯 Key KPIs

- Cross-Sell Achievement %
- New Business Achievement %
- Renewal Achievement %
- Invoice Achievement %
- Meeting Count by Account Executive
- Invoice Count by Account Executive
- Revenue by Opportunity
- Opportunity Product Distribution
- Stage Funnel by Revenue
- Yearly Meeting Count

 🛠️ Tools & Technologies

- SQL
- Python
- Excel
- Power BI
- Tableau
- Data Cleaning
- KPI Analysis
- Data Visualization
- Dashboard Development

 💡 Business Insights

The dashboard helps monitor insurance sales performance, identify high-performing Account Executives, analyze opportunity revenue, and track cross-sell, new business, renewal, and invoice achievement.
